# To-Do List Web App

A clean beginner web app for adding, completing, filtering, and deleting daily tasks.

## Features

- Add new tasks
- Mark tasks as complete
- Filter all, active, and completed tasks
- Delete tasks
- Saves tasks in browser local storage

## Concepts Practiced

- HTML structure
- CSS styling
- JavaScript DOM manipulation
- Events
- Local storage

## Run Locally

Open `index.html` in a browser.

## Future Improvements

- Add due dates
- Add task priority
- Add edit task option
